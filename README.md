# کنترل سفارش تکنو یدک — نسخه ۳۴

## اصلاح‌های این نسخه

### ۱) نام مشتری در فاکتور عکس یا PDF
- بعد از OCR فاکتور، برنامه متن OCR را برای عنوان‌های مشتری/خریدار و نام‌های همراه عنوان‌هایی مانند «جناب آقای» و «خانم» بررسی می‌کند.
- نام پیدا‌شده در فیلد «نام مشتری / فروشگاه» نمایش داده می‌شود.
- اگر نام به‌طور مطمئن در متن OCR پیدا نشود، برنامه پیام می‌دهد تا کاربر نام را دستی وارد کند؛ نام فاکتور قبلی روی فاکتور جدید باقی نمی‌ماند.
- ورود اکسل همچنان مستقیماً از سلول‌های اکسل انجام می‌شود و OCR اجرا نمی‌شود.

### ۲) OCR لیبل بسته
- عکس قبل از ارسال به OCR به کمتر از ۹۰۰ کیلوبایت فشرده می‌شود تا از سقف معمول ارسال فایل در طرح رایگان OCR.space عبور نکند.
- درخواست لیبل با حالت OCR غیرجدولی Engine 3 اجرا می‌شود تا زبان فارسی پشتیبانی شود؛ OCR فاکتور همچنان از حالت جدول Engine 3 استفاده می‌کند. تفاوت لیبل در خاموش بودن تشخیص جدول و مختصات overlay است.
- الگوهای خواندن تعداد شامل «تعداد داخل بسته: ۵»، «۵ عدد»، `5 PCS`، `QTY: 5` و «بسته شامل ۲۰ عدد» است.
- عددی که صریحاً تعداد بسته را نشان ندهد حدس زده نمی‌شود. در صورت ابهام، متن خام OCR در صفحه نمایش داده می‌شود تا امکان بررسی فراهم باشد و تعداد را می‌توان دستی وارد کرد.

### ۳) عیب‌یابی
- خطاهای سمت API با پیام قابل‌مشاهده نشان داده می‌شوند.
- جزئیات متن خام لیبل در بخش «متن خام خوانده‌شده از لیبل» بازشدنی است.

## تست‌های محلی

این تست‌ها بدون ارسال تصویر به سرویس OCR اجرا می‌شوند:

```bash
node --check server.js
node --check invoice-import.js
node tests/test-import.js
node tests/test-import-real-layout.js
```

در آزمون مرورگر Playwright با پاسخ OCR شبیه‌سازی‌شده:
- نام مشتری از متن OCR فاکتور در فیلد مشتری نمایش داده شد.
- مقدار «تعداد داخل بسته: ۵ عدد» به ۵ تبدیل شد.
- فرمت‌های `5 PCS`، `QTY: 5`، «بسته شامل ۲۰ عدد» و «تعداد: ۱۰» به‌درستی تشخیص داده شدند.
- هیچ خطای JavaScript هنگام بارگذاری و اجرای جریان‌های تست ثبت نشد.

**محدودیت مهم:** سرویس OCR زنده و دوربین گوشی در این محیط قابل آزمایش نهایی نیستند. دقت نهایی همچنان به کیفیت عکس لیبل و پاسخ سرویس OCR بستگی دارد؛ در صورت ابهام، برنامه تعداد را حدس نمی‌زند.

## انتشار روی GitHub و Render

تمام محتویات این ZIP را در ریشه مخزن `yaser1700/techno-yadak-ocr` قرار بده و فایل‌های هم‌نام را جایگزین کن. چون تنظیمات OCR لیبل در `server.js` است، فقط `public/index.html` را عوض نکن. Commit کن و تا وضعیت `Live` در Render صبر کن.
