# کنترل سفارش تکنو یدک — نسخه ۳۱

این نسخه روی نسخه ۳۰ ساخته شده و اصلاحات زیر را دارد:

- استخراج نام خریدار از سطر دارای «نام خریدار/نام مشتری» در فایل اکسل؛ برای سلول‌های ادغام‌شده، کل سطر بررسی می‌شود.
- اسکن بارکد ابتدا از BarcodeDetector داخلی مرورگر استفاده می‌کند و در صورت نبودن آن، از html5-qrcode به‌عنوان روش جایگزین استفاده می‌کند.
- نمایش پیام روشن در صورت خطای دسترسی دوربین یا نبودن پشتیبانی مرورگر.
- نوار ناوبری مراحل برای استفاده ساده‌تر در موبایل.
- تعداد واقعی بسته به‌صورت اجباری وارد می‌شود؛ برنامه به‌طور خودکار عدد ۱ فرض نمی‌کند.
- خطاهای ثبت جمع‌آوری در خود صفحه نمایش داده می‌شوند.
- ردیف‌های دارای مغایرت در ابتدای گزارش کنترل نهایی نمایش داده می‌شوند.

## استقرار
محتویات این پوشه را در ریشه مخزن `yaser1700/techno-yadak-ocr` جایگزین کنید و Commit کنید تا Render استقرار مجدد انجام دهد. متغیر محیطی `OCR_API_KEY` باید فقط در Render تنظیم شده باشد.

## وضعیت آزمون
- `node --check server.js`: موفق.
- بلوک‌های JavaScript داخل `public/index.html`: بررسی نحوی موفق.
- استخراج نام خریدار بر اساس ساختار فایل اکسل نمونه `1234.xlsx` بازبینی شد؛ انتظار خروجی «جناب آقای کاظمی ( پرند )» است.
- آزمون HTTP زنده/اجرای کامل سرور در محیط ساخت انجام نشد، چون وابستگی‌های npm در محیط محلی نصب نبودند. قبل از استفاده عملی، پس از Deploy یک فاکتور نمونه و یک بارکد واقعی را آزمایش کنید.
- سفارش‌ها هنوز در حافظه سرور نگهداری می‌شوند و برای پایداری بعد از restart نیاز به دیتابیس دائمی دارند.
