# کنترل فاکتور تکنو یدک — نسخه ۲۱

## تغییرات این نسخه
- تشخیص ستون تعداد با استفاده از موقعیت سربرگ «مقدار/تعداد» روی تصویر OCR؛ به‌جای محدوده افقی ثابت که شرح کالا را با تعداد اشتباه می‌گرفت.
- اگر ستون تعداد یا مقدار همان ردیف با اطمینان پیدا نشود، خانه تعداد خالی می‌ماند و ردیف برای بررسی دستی علامت می‌خورد؛ عددی از شرح کالا به‌عنوان تعداد حدس زده نمی‌شود.
- ارسال مأموریت وقتی یک یا چند تعداد خالی/صفر باشد، متوقف می‌شود تا تعداد اشتباه وارد مأموریت نشود.
- اصلاح ساختار اسکریپت صفحه برای اینکه کدهای مربوط به مأموریت مدیر/کارگر اجرا شوند.
- شناسه مأموریت همان شماره فاکتور است.

## نصب
1. محتویات ZIP را استخراج کنید.
2. همه فایل‌ها و پوشه‌های داخل آن را در ریشه مخزن `yaser1700/techno-yadak-ocr` جایگزین فایل‌های هم‌نام کنید.
3. Commit کنید و منتظر Deploy شدن Render بمانید.
4. همان فاکتور نمونه را دوباره آزمایش کنید.

## نکته آزمون
این نسخه باید روی همان فاکتور بررسی شود. معیار نمونه: ۵ قلم و تعدادهای ۵، ۱۰، ۱۰، ۴، ۵. اگر سربرگ/ستون تعداد در عکس تشخیص داده نشود، تعداد خالی و نیازمند اصلاح دستی می‌ماند؛ به‌جای اینکه عددی مانند ۱۳۱ از شرح کالا برداشته شود.

## Environment
متغیر `OCR_API_KEY` باید در Render Environment Variables تنظیم شده باشد.
