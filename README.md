# کنترل سفارش تکنو یدک — نسخه ۳۳

## اصلاح دو دکمه غیرفعال

در نسخه قبلی، کد مربوط به دریافت مأموریت و ارسال سفارش در یک بلوک JavaScript تکراری و جداگانه قرار داشت. به‌دلیل تعریف دوباره متغیرها و توابع سراسری، مرورگر اسکریپت اصلی را اجرا نمی‌کرد و در نتیجه رویداد دکمه «افزودن نام کارگر» و «استخراج اکسل» نیز نصب نمی‌شد. بلوک تکراری حذف شده و اسکریپت‌ها باهم از نظر نحوی بررسی شده‌اند.

- «افزودن نام کارگر» اکنون یک فرم داخل صفحه باز می‌کند (به `prompt` مرورگر وابسته نیست) و پس از ثبت، نام در فهرست انتخاب می‌شود.
- هنگام انتخاب فایل اکسل، نام و حجم فایل روی صفحه نمایش داده می‌شود.
- دکمه استخراج اکسل خطاهای اتصال یا نسخه قدیمی سرور را واضح‌تر گزارش می‌کند.
- مسیر `/api/import-invoice` در `server.js` حفظ شده و فایل‌های `invoice-import.js` و `package.json` در این بسته هستند.

## آزمون‌های انجام‌شده محلی

- `node --check server.js` و `node --check invoice-import.js`.
- `node tests/test-import.js`.
- بلوک‌های JavaScript صفحه جداگانه و به‌صورت ترکیبی بررسی شدند؛ تعریف تکراری سراسری باقی نمانده است.
- آزمون مرورگر با پاسخ شبیه‌سازی‌شده API: افزودن و انتخاب کارگر، انتخاب فایل `1234.XLS`، اجرای رویداد استخراج، نمایش شماره فاکتور `17927`، نام مشتری «جناب آقای کاظمی (پرند)»، سه ردیف، جمع تعداد `120` و ارسال مأموریت بررسی شد. در این آزمون مرورگر هیچ خطای JavaScript ثبت نشد.
- تابع استخراج با ردیف‌های واقعی فایل اکسل تبدیل‌شده از فاکتور نمونه بررسی شد: کدهای `11401`، `18501` و `25802` با تعدادهای `50`، `50` و `20` و جمع `120`.

**محدودیت:** آزمون مرورگر برای endpoint از پاسخ شبیه‌سازی‌شده استفاده کرد؛ سرور Render زنده از این محیط قابل تأیید نهایی نبود. پس از Deploy باید همان فاکتور روی سایت واقعی یک‌بار بررسی شود.

## انتشار روی GitHub و Render

**محتویات این ZIP را مستقیماً در ریشه مخزن `yaser1700/techno-yadak-ocr` قرار بده**؛ پوشه والد یا خود ZIP را داخل مخزن قرار نده. فایل‌های هم‌نام را جایگزین کن و همه فایل‌های زیر را با هم Commit کن:

- `server.js`
- `invoice-import.js`
- `package.json`
- پوشه `public/` شامل `index.html` و `products.js`
- پوشه `tests/`
- `render.yaml` و `.gitignore`

سپس در Render منتظر بمان سرویس دوباره Deploy شود و وضعیت `Live` باشد. برای واردکردن اکسل، نسخه جدید فقط با جایگزینی `public/index.html` کافی نیست؛ endpoint اکسل داخل `server.js` است و ماژول تجزیه در `invoice-import.js` قرار دارد.

## محدودیت فعلی

نام کارگران این نسخه فقط در مرورگر همان دستگاه ذخیره می‌شود. مأموریت‌ها نیز در حافظه سرور هستند و پس از راه‌اندازی مجدد ممکن است از بین بروند؛ برای استفاده پایدار چندنفره باید ذخیره‌سازی دائمی اضافه شود.
